# 日历清单 · Calendar List `v0.1.1` 发行说明

**发布日期**：2026-10-27  
**版本标签**：`v0.1.1`（正式发布版）  
**适用平台**：Windows 10 / 11 (x64)

---

## 一、`v0.1.1` 核心升级与体验精修

1. **默认仅展示左侧日历区域 + 设置中心「显示右侧展示栏」自由开关**
   - 响应用户纯粹桌面日历诉求：**默认只展示左侧 42 格日历矩阵**（隐藏右侧展示栏），界面更清爽专注；双击任意日历格空白处即可直接输入安排，双击已有安排可原位修改文字（清空内容按 `Enter` 可直接删除）。
   - 若需要使用右侧展示栏，只需打开 **「右上角 ⚙ 设置 → 桌面与自启 → 显示右侧展示栏」** 勾选开启，即可实时恢复左右双栏视图。

2. **日历格内多条安排自动换行修复（告别死板的 `...` 单行截断）**
   - 重构日历单元格（`.kal-cell`）内多任务（`.is-multi-tasks` / `.is-crowded`）排版规则：解除第 2、3 条安排此前被强制设为单行 `nowrap` 省略号（`...`）的限制，恢复多行自然换行（`pre-wrap`），充分利用日格纵向高度完整展示安排内容。

3. **右侧展示栏圆圈（`⭕️`）与文本高度像素级垂直对齐**
   - 统一右侧清单圆点按钮（`.kal-agenda-dot`）、时间标签（`.kal-agenda-time`）与事项正文（`.kal-agenda-text`）的首行行高基准，消除圆圈与右侧文字的高低错位。

4. **右侧展示栏布局精简与「近期安排」概览**
   - 移除右侧展示栏顶部低频冗余按钮组（`N项 / 撤销 / 顺延 / 复制 / ICS`），替换为清爽的相对日期胶囊（`今天 / 明天 / 后天`）；
   - 移除底部无实际使用场景的折叠抽屉（`重要日期 / 便签本 / 节假日配置`），消除清单与 `+ 添加安排` 之间的大片空白区域，并在下半区内置零配置的 **「近期安排」** 概览列表，自动汇总当月后续待办并支持一键点击跳转。

5. **安装目录就地数据存储（`data/`）与无缝覆盖升级继承**
   - **告别 C 盘堆积**：当安装在独立应用目录（如 `D:\1_app\CalendarList`）时，所有用户数据（`settings.json`、`sandbox/kal_sandbox.db`、`backups/`、`themes/`、`fonts/`、`logs/kal.log` 及 `webview2/` 缓存）统一存储于软件安装目录下的 **`data/`** 文件夹中；
   - **老版本无感迁移与覆盖升级保护**：从 `v0.1.0` 覆盖安装升级至 `v0.1.1` 时，NSIS 安装钩子自动停止运行中的旧进程、默认完整保留并继承既有日程、设置、自定义主题与操作日志（自动从 `%APPDATA%\Kal` 迁移并维护双写热备快照），用户只需一路点击「下一步」即可无损完成升级。
   - **支持只读导入外部 `.db` 数据库**：在顶栏「导出 → 导入原版 `.db`」中支持直接选择原版 `calendar.db` / `dcal.db` 只读无损导入历史日程。

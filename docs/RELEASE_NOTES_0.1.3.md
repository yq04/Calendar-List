# 日历清单 v0.1.3

本次更新新增桌面壁纸分区，将日历、软件和文件区域安排在同一张静态壁纸上；同时改进分区调整精度、屏幕适配和设置中心的显示样式。

## 主要改进

- **壁纸分区**：支持右侧日历、左侧日历及上下布局，提供均衡、疏朗、紧凑三种比例，保留适当的壁纸展示空间。
- **留白与精调**：默认四周预留一格桌面图标间距，可选两格或不留白；支持像素输入、1px 键盘微调、吸附参考线、八向缩放、放大编辑及分区内撤销重做。
- **外观与屏幕适配**：提供柔和、清透、深色板面配方，使用渐变、细边框和统一标题；按实际工作区、DPI、图标网格及可信的物理尺寸适配，不按英寸硬编码分辨率。
- **逐屏应用与恢复**：生成独立壁纸副本，只应用于所选显示器，并对齐实时日历窗口；保留原壁纸快照，恢复时避免覆盖用户后来手动选择的新壁纸。
- **设置样式统一**：统一「高级微调」的字体、字号和细线展开图标。界面版本优先读取实际程序版本。
- **版本信息准确**：更新应用内功能说明；「查看版本」仅报告本机版本，不再把未联网检查描述为“已是最新版本”，移除尚未接入的自动检查开关。

默认保持纯月历视图，右侧展示栏按需开启；日期格内的事项继续完整换行，空间不足时可在格内滚动。分区应用与主题、字体等未保存的外观草稿相互独立。

## 开始使用

进入「设置 → 背景画布 → 桌面壁纸分区」，选择显示器与静态图片，选定布局后点击「应用分区」。已有自定义布局不会在升级时自动重排，可手动选择新布局或使用「一键留白」。

软件、文件分区是视觉区域，桌面图标仍由 Windows 管理，需要手动拖入；不会自动分类或搬移真实文件。详见 [桌面壁纸分区使用说明](https://github.com/yq04/Calendar-List/blob/v0.1.3/docs/desktop-wallpaper-zones.md)。

## 安装与升级

系统要求为 Windows 10/11 x64 和 WebView2 Runtime。安装包不包含完整 WebView2 运行时；缺少运行时的电脑可能需要联网安装。

升级前先从系统托盘正常退出日历清单，并备份安装目录下的 `data` 文件夹；旧版可能使用的 `%APPDATA%\Kal` 也应备份。更新时使用原安装路径；新版安装器遇到运行实例会要求先退出，不主动强杀程序。

旧版 v0.1.1 的卸载器含强制结束进程行为。覆盖更新时建议使用 `/UPDATE` 模式跳过旧卸载器：

```powershell
Start-Process -FilePath '.\CalendarList_0.1.3_x64-setup.exe' -ArgumentList '/UPDATE' -Wait
```

已完成指定本机的安装、启动及升级前后数据文件哈希核对；这不代表所有安装路径切换、卸载或旧版迁移组合均已验收。

## 验证与支持边界

- 分区模型 20 组检查通过，包含 15 种合成屏幕参数下的 135 个布局组合。
- 实际前端页面的 22 项隔离 Mock 检查通过，覆盖布局、配方、像素精调、竖屏、草稿隔离及图片输出。
- Rust 前后端配置与窗口几何一致性检查通过，覆盖 4 组代表性合成配置。
- 发布前另通过 9 项 Rust 分区校验与隔离事务检查、8 项版本页检查；未将跳过的原生检查计为通过。
- 浅色、深色及复杂合成壁纸的分区外像素严格比对一致，包含外围留白和任务栏区域。

当前支持静态图片与逐显示器布局。跨屏 Span、系统壁纸幻灯片、动态壁纸和自动图标整理尚未支持。上述合成与 Mock 检查不等于所有 24/27 英寸、1080p/1440p/4K 电脑均已实测；真实 Windows 壁纸应用/恢复、日历窗口贴合及混合 DPI 热插拔仍需实机验收。

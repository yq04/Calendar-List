# 桌面壁纸分区

在「设置 → 背景画布 → 桌面壁纸分区」选择显示器和壁纸，安排日历、软件和文件区域。可以使用当前静态壁纸，也可以选择自己的 JPG、PNG、BMP 或 WebP 图片，无需专门制作图库。

## 调整布局

选择右侧日历、左侧日历或竖屏布局后，可以选择「均衡」「疏朗」「紧凑」三种比例。均衡保留日历与图标区之间的呼吸空间，疏朗展示更多壁纸景物，紧凑适合可用空间较小的屏幕；程序根据实际工作区与缩放选择可用布局。

默认在工作区四周留出一格桌面图标的间距。间距按目标屏的 Windows 图标网格和 DPI 计算，不再按屏幕百分比估计。可以选择不留白、一格或两格；点击「一键留白」整理当前布局，并保留已有留景比例。已有自定义布局不会在升级时被自动重排。小屏幕上的模板会适当减少留白，优先保证日历内容可读。

默认以实际像素显示位置和尺寸，支持直接输入左侧、顶部、宽度和高度，也可切换百分比。选中分区后，方向键移动 1 像素，Shift + 方向键移动 10 像素，Ctrl + 方向键调整尺寸。分区名称和实际尺寸在预览里保持清晰，边角手柄均可拖动缩放。

拖动时可吸附到边界、其他分区和间距参考线；按住 Alt 临时关闭吸附，或用像素输入精调。边界和碰撞约束防止分区被拖出屏幕或穿过其他分区。需要更大操作空间时，点击「放大编辑」，按 Escape 返回设置；分区内的撤销和重做独立于日历事项与主题草稿。

底板提供柔和、清透、深色配方，也可在微调中选择自动、浅色或深色并调整强度。自动模式为日历提供暖浅底板、为桌面图标提供蓝灰底板，结合壁纸区域明度、细边框和柔和渐变保持层次。配方只改底板，不改变已有分区几何；再次点击已选配方恢复默认。预览和应用使用同一绘图流程，输出按目标显示器实际像素生成。

目标屏说明展示分辨率、Windows 缩放和可信的物理英寸。布局根据有效工作区、DPI、图标网格适配 24/27 英寸等屏幕，绘图以有界 PPI 修正帮助保持标题物理大小；硬件未报告物理尺寸时使用分辨率与 DPI，不猜测英寸。这些机制不等于每款显示器均已实机验收。

点击「应用分区」后，程序生成新的壁纸副本，只应用到所选显示器，并将实时日历固定到日历分区。软件和文件区域是壁纸上的视觉区域，将桌面图标拖入即可；文件位置不变。系统的图标自动排列可能限制手动放置，可在 Windows 桌面右键菜单中自行调整。

## 保存与恢复

「应用分区」和「恢复原壁纸」独立生效，不依赖设置顶部的外观保存按钮。调整主题、字体等未保存草稿不会因分区操作被提交。

程序保留原壁纸快照，原图不会被覆盖。恢复时也恢复分区应用前的日历固定方式。如果已在 Windows 中另选壁纸，恢复操作会保留新壁纸并提示，不用旧快照覆盖它。

壁纸副本及恢复记录保存在应用数据目录，日历事项数据库不参与这项操作。应用关闭后，静态分区仍是桌面壁纸的一部分；日历本身需要程序运行才能显示和编辑。

## 当前范围

支持 Windows 10/11 的静态壁纸以及逐显示器布局。跨屏 Span 和系统壁纸幻灯片会阻止应用，并提示先改用静态壁纸；不会改变全局壁纸填充模式或其他屏幕的壁纸。动态壁纸、自动分类/搬移桌面图标、文件容器及自动跟随壁纸轮播尚未提供。

多显示器采用完整屏幕和工作区的物理坐标，分区保存为工作区比例。20 组模型检查包含 15 种合成屏幕参数下的 135 个布局组合，另有 22 项实际页面的隔离 Mock 检查。它们验证了布局与交互，但没有实际替换正式桌面壁纸；真实 Windows 壁纸应用/恢复、日历窗口贴合、混合 DPI、热插拔和全部任务栏位置仍需要实机验收。

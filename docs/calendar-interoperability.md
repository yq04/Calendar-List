# ICS 兼容范围

当前事项模型仅保存日期、分钟和标题。导入仅接受一次性 VEVENT：本地浮动时间（秒必须为 00）或单日全天日期。全天 DTEND 是独占日期，仅接受次日；定时事件不接受 DTEND，因为模型不能保存结束时间。UTC、TZID、重复规则及例外、跨日和持续时间均跳过，并提供原因。嵌套组件、无效日期以及文件中重复 UID 的事件也跳过。

`parseIcsCalendarDetailed` 返回 `{items, skipped, warnings, errors}`，界面应在写入前展示跳过原因与警告。结构错误时不返回任何事项。有效事件的 UID 会传给导入后端，缺少 UID 时以内容作为去重依据；附加属性不保存，会产生警告。旧 `parseIcsCalendar` 返回事项数组，调用方应迁移到详细接口以向用户显示这些信息。

导出使用浮动时间或单日全天日期；定时事项不生成虚构的结束时间。此实现不承诺完整 RFC 5545 兼容，也不展开重复事件或转换时区。

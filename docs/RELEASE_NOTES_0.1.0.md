# 日历清单 · Calendar List `v0.1.0` 发行说明

**发布日期**：2026-10-26  
**版本标签**：`v0.1.0`（正式发布版）  
**适用平台**：Windows 10 / 11 (x64)

---

## 一、核心亮点

1. **壁纸式常驻融合与设置全分区一键还原默认**
   - **常驻壁纸融合透明度（`0% ~ 100%`）**：在「设置 → 桌面与自启」新增 `全透 0% / 轻透 35% / 半透 65% / 微透 85% / 实底 100%（默认）` 快捷档位与无级滑杆，日历固定在壁纸上时保持恒定透明度，不会因鼠标移出而忽明忽暗（同时保留可选的「鼠标移开时进一步减淡」开关，默认关闭）。
   - **顶栏「透明底 / 还原实底」与设置全分区无损还原**：点击顶栏「透明底」可一键切换全透悬浮并自动记忆切换前快照，再次点击立即还原最初实底状态；设置面板内所有分区（预设主题、窗口质感、日历排版、精选字体、艺术背景画布、壁纸取色、高级微调分组）均配备独立「恢复默认」按钮，且再次点击任意已激活卡片即可退回默认状态。

2. **多显示器、横竖屏方向与 24"/27" 物理 PPI 自适应**
   - 自动检测所有显示器的工作区坐标、横竖屏方向（`[横屏]` / `[竖屏]`）、物理英寸（如 `24.0"` / `27.0"`）与 DPI 缩放比。
   - 提供 **8 种桌面固定位置预设**（占据屏幕左侧、左侧避让图标、左侧适中尺寸、占据屏幕右侧、桌面居中固定、**占据屏幕上半区（竖屏推荐）**、**占据屏幕下半区（竖屏适用）**、原地锁定位置），竖屏副屏下自动优化高宽比例，窗口跨屏或旋转时自动重算 PPI 缩放。
   - 普通窗口模式下支持 Windows 任务栏显示与顶栏右上角「最小化 / 隐藏到系统托盘」快捷控制；固定到桌面时自动隐藏任务栏图标与窗口控制按钮，纯粹融入壁纸。

3. **左右双侧原位直编 + 中文自然语言速记 + 单日 8 色高亮**
   - **左侧 42 格日历直接编辑**：双击任意日期格空白处（或点击日格右上角悬停 `+` 按钮）即可原位新建，双击格内已有事项即可原位改字。
   - **右侧日程清单直接编辑**：支持顶部快速输入、底部 `+ 添加安排` 原位新建、双击已有事项改字，以及 `Ctrl+Z` / `Ctrl+Y` 多步撤销重做。
   - **中文自然语言速记与单日底色标记**：支持输入 `明天下午3点半 项目评审 !1 #核心` 自动识别日期、时间、优先级与标签；展开时间选项栏即可为任意日期设置 **8 色单元格底色高亮**。

4. **满格防溢出、防吞字与底栏常驻 `+N 更多`**
   - 单格含 1 条长事项时自然多行换行；含 2 条事项时每条限高 2 行；含 **3 条及以上事项**（`.is-crowded`）时，自动切换为紧凑单行省略显示，并将 **`+N 更多`** 胶囊独立固定在日格底栏，点击即可弹出当日完整清单。

5. **OKLab 壁纸取色引擎、5 套内置主题与同页字体搜索**
   - 内置 **星港素纸（默认）、深海夜航、摩卡夜读、极北霜蓝、晨纸微光** 5 套高对比度主题与 8 色强调色快选。
   - 「排版与字体」页面集成精选字体模板、本地字体导入、字体搜索框及系统/私有字体下拉选择器，搜索关键字实时过滤下拉列表。

6. **周视图看板、A4 横向满幅打印导出与独立沙盒存储**
   - 一键切换 **月视图（42 格）** 与 **周视图（7 列纵向看板）**，支持鼠标拖拽跨日改期与未完事项一键顺延。
   - 支持导出 **A4 / A3 / Letter 横向满幅矢量 PDF**、**Markdown (`.md`)** 及标准 **iCalendar (`.ics`)** 双向导入导出。

# 日历清单 · Calendar List `v0.1.0` 发行说明

**发布日期**：2026-10-26  
**版本标签**：`v0.1.0`（首次公开正式候选版）  
**适用平台**：Windows 10 / 11 (x64)

---

## 一、核心亮点

1. **左右双侧原位直编（Dual-Pane Direct Inline Editing）**
   - **左侧 42 格日历直接编辑**：双击任意日期格空白处（或点击日格右上角悬停浮现的 `+` 按钮），即可在该日格内直接弹出输入框，回车即存（支持连按回车连续新建多条）；双击格内任意已有事项即可原位改字。
   - **右侧日程清单直接编辑**：既可通过右侧顶部快速输入框一键回车添加，也可点击列表底部 **`+ 直接添加安排`** 或双击右侧任意事项卡片进行原位编辑。
   - **默认无具体时间负担**：日常待办默认不设具体时间点，保持画面纯粹；需要设置具体时刻、跨日日期或重要度时，按需点击 `🕒` 展开手动时间抽屉即可。

2. **满格防溢出、防吞字与底栏常驻 `+N 更多`**
   - 单格内含 1 条长事项时自然多行换行；含 2 条事项时每条限高 2 行；含 **3 条及以上事项**（`.is-crowded`）时，自动切换为紧凑单行省略显示，并将 **`+N 更多`** 胶囊独立固定在日格底栏（绝不出现文字半行被截断或 `+N 更多` 被挤出视野的问题）。
   - 点击 `+N 更多` 即可弹出该日全量事项悬浮卡片，同时右侧面板完整展示当日全部安排。

3. **极简温润排版与低配电脑友好设计**
   - 默认搭载 **星港素纸** 护眼暖白主题，移除冗余黄历「宜/忌」与繁杂胶囊标签，清晰突出 **日期 + 星期** 与 **农历 / 二十四节气 / 法定休班角标**。
   - 顶部 `[ ‹ 今天 › | 周视图 ]` 采用紧凑无框胶囊设计，左右两侧卡片边框、圆角、字重与行高全面统一。
   - 内置 **减少动画（Reduced Motion）** 开关与 **温润实底** 零模糊模式，兼顾轻薄本、核显与老旧办公电脑的丝滑流畅体验。

4. **OKLab 壁纸取色引擎与 5 套内置主题**
   - 内置 **星港素纸、深海夜航、摩卡紫蓝、极地霜夜、松影晨纸** 5 套静态主题，以及 **8 色强调色快选矩阵**。
   - 支持从当前桌面壁纸或自定义图片实时采样，基于 **OKLab 加权 k-means + 二分对比度校正** 自动生成符合 WCAG AA/AAA 可读性标准的专属主题。

5. **周视图看板、A4 横向满幅打印导出与独立沙盒存储**
   - 一键切换 **月视图（42 格）** 与 **周视图（7 列纵向看板）**，支持鼠标拖拽跨日改期、未完成事项一键顺延与单步撤销。
   - 支持导出 **A4 横向满幅 PDF / 打印预览**、**Markdown (`.md`)** 及标准 **iCalendar (`.ics`)** 文件。
   - 支持 **独立本地 SQLite 沙盒模式**（开箱即用，无需外部软件）与 **DesktopCal 兼容只读/MCP 桥接模式**。

6. **设置与工作台 `v0.1.0`**
   - 支持 **简体中文 / 繁體中文 / English** 三语实时切换。
   - 内置 **操作日志与历史面板**（支持复制、导出 `.json` 与清空）及 **版本与检查更新** 卡片。

## 做了什么

系统层新增默认关闭的 Win+Alt+C 全局呼出、重复启动唤醒、临时置顶/再次收起/失焦恢复，以及热键占用提示和重试。单实例使用当前交互会话的 Local 互斥锁和事件，CLI 自检不受限制。

字体支持 Kal 私有目录的 ttf/otf/woff/woff2，设置中刷新并按需加载选中字体，随主题保存和恢复。字体宽度作为主题字段持久化。文件大小、总加载量、路径穿越和 Windows 重解析点受到限制，启动加载失败保留可见错误。

日程栏新增本机倒计时与跨日期只读便签浏览。倒计时按自然日而非毫秒计算，保存失败保留旧卡片；便签按 50 条分页，展开才读正文，以纯文本显示并支持复制。设置读改写周期增加进程内互斥，避免并发保存丢失其他模块设置。工具区复用主题色与滚动条。

## 遗留什么

真实 DesktopCal CRUD、确认与多端云同步尚未联调。带时间事件新增仍关闭，便签仍只读。Win10/11 跨版本、非管理员 WorkerW、全屏应用和多屏切换尚未完成跨设备验收。含 WebView2 子进程的总内存本轮未重测。

便签正文以纯文本显示，超长正文明确截断；图片和富文本编辑未接入。字体支持的实际字宽变化取决于所选字体是否具备相应宽度轴。

## 设计偏差

单实例从旧 Global 互斥锁改成当前交互会话的 Local v2 协议，以免不同登录会话相互阻止。旧版进程与新版协议不互通，升级前正常退出旧版。

倒计时仅保存在 Kal 本机设置，便签浏览走只读数据库；没有借此改变原有云同步和生产写入边界。字体采用 FontFace 二进制按需加载，避免整目录 Base64 常驻。桌面技术栈与零 npm 约束保持一致。

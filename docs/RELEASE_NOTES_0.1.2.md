# 日历清单 · Calendar List `v0.1.2` 发行说明

**发布日期**：2026-10-27<br>
**版本标签**：`v0.1.2`（正式发布版）<br>
**适用平台**：Windows 10 / 11 (x64)

---

## 一、`v0.1.2` 核心升级与体验精修

1. **设置中心交互体验与草稿隔离**
   - **设置透显查看（「查看日历」）**：设置中心顶栏新增「查看日历」快捷透显按钮，支持在调整配色、质感与排版时临时隐藏设置内容以对照底层日历的实际渲染效果，无需反复关闭与重新打开设置弹窗；
   - **明确预览状态与防误触提示**：未保存修改时明确显示「`● 预览中 · 未保存`」状态标记，重置与关闭按钮补充详细提示（区分“放弃未保存预览还原至打开时状态”与“一键恢复全部默认”），关闭弹窗自动丢弃临时草稿；
   - **草稿独立隔离**：界面主题草稿与已持久化的用户配置解耦，未明确点击「保存设置」前不改写已生效配置；事项输入会话维护独立草稿生命周期，降低并发输入时的状态覆盖概率；
   - **常驻透明度即时生效**：固定背景透明度滑杆或快捷档位选择在松开/选中后即时写入配置，其他外观调整仍集中于保存按钮统一应用。

2. **资源缓存与内存预算优化**
   - **壁纸有界 LRU 缓存**：壁纸背景管理器内置上限 2 项、32MB 内存预算的 LRU 缓存机制，并对并发重复请求实施合并，避免在主题频繁切换时反复读取大图导致内存激增；
   - **私有字体防重复加载**：本地字体加载器建立请求去重机制，对已激活字体与系统内置字体跳过冗余 IPC 传输与磁盘读取。

3. **NSIS 安装与卸载温和防护（新版不再强杀）**
   - **新版安装器温和退出**：本次 `v0.1.2` 安装与卸载逻辑（`hooks.nsh`）已移除静默 `taskkill` 强杀逻辑，当检测到程序正在运行时，要求用户先通过托盘正常退出，从不强杀进程，降低未保存数据丢失风险；
   - **旧版安装器行为提示**：需注意历史旧版安装器（如真实的 `v0.1.1` 安装包）仍可能包含强杀运行中进程的历史行为，用户在执行跨版本升级或使用旧版卸载器前，建议主动先从系统托盘退出旧版程序；
   - **数据目录配置保护**：安装阶段不再硬性改写 `DataDir` 存储配置，降低更换安装目录时覆盖既有就地数据的风险。

4. **SQLite 本地存储快照与路径安全防御**
   - **只读快照机制**：引入 `snapshot_sqlite` 辅助流程，使用 SQLite 原生在线备份 API（`Backup`）复制处于活跃事务（含 WAL）的数据库快照副本，并在快照生成后附带 `PRAGMA integrity_check` 校验；
   - **符号链接拦截**：在数据路径处理中增加符号链接检测（`reject_link`），禁止向符号链接目标写入，规避非预期路径跨目录写入。

5. **iCalendar (`.ics`) 互操作透明化与有限子集规范对齐**
   - **明确有限子集规范**：全面对齐 [ICS 兼容说明](calendar-interoperability.md)，明确当前仅支持单日一次性日程或本地浮动时间事项，纠正此前文档对标准完整支持的表述；
   - **提供跳过与告警反馈**：解析器升级为 `parseIcsCalendarDetailed`，对重复规则（RRULE）、跨日多天日程、非浮动时区等暂未支持的复杂字段提供明确跳过原因与告警列表，不虚构结束时间，避免静默丢弃。

6. **月历排版与文字折行微调**
   - 优化月历矩阵排版规则，进一步放宽格内多任务文字折行限制，减少长文本截断；
   - 清理主题设置中心内的冗余主题快照卡片。
